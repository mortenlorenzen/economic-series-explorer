# Retro

One line per phase: what went wrong, what the spec missed, what to change in the kit.
- 2026-11-02 Phase 1 scaffold: Quarto rendered every .md (BRIEF, specs) into the public site and a bare `js/` resource glob also published `tests/js/`; renv implicit snapshot missed testthat called only from a shell script → kit: tech-stack template should prompt for "what the site publishes" (render list, resources) on Quarto projects
- 2026-11-02 Phase 2 first-series: spec said "4 decimals" without looking at the data — Yahoo float32 noise needed 7 significant digits; jsonlite auto_unbox turned 1-element arrays into scalars (caught by reviewer) → kit: feature-spec step should fetch one real sample before fixing number formats
- 2026-11-02 Phase 3 registry-pipeline: my "one series fails" test failed both series so it proved nothing, collected errors lacked ids, and R as.Date guessed its format from the first element (leap-day bug) — all caught by reviewer → kit: validation template should ask "does each failure test fail exactly one thing?"
- 2026-11-02 Phase 4 daily-data: the constitution missed that the PR-only ruleset blocks automated data commits, so the phase stopped for a question; answer A then proved impossible (personal repos can't add the Actions app as a bypass actor) and was revised to B → kit: constitution should read branch rulesets via `gh api` and check what the account type allows when a workflow will push to main
- 2026-11-02 Phase 5 front-end-core: Quarto 1.10.19 loads Plot 0.6.11 (no observable10 scheme) — found only by reading the runtime; the browser extension was not connected, so UI checks ran through a scratch CDP script on headless Chrome → kit: tech-stack should pin the OJS library versions Quarto loads, and the kit could ship a small headless-Chrome check script
- 2026-11-02 Phase 6 rates-panels: spec said "plot height" where it meant SVG height, and page logic (subtitle, panel choice) first lived untested in index.qmd → kit: requirements template could ask "which logic is pure and belongs in the tested module?" up front
- 2026-11-02 Phase 7 actual-log: "include 0" in my spec contradicted BRIEF's "start the y-axis at zero" and a test locked in the wrong reading; my first browser script clicked radios while they were still disabled (OJS updates async) → kit: browser checks need a wait-for-state helper, and specs should quote the brief verbatim for numeric/axis rules
- 2026-11-02 Phase 8 cache-downsampling: the brief was silent on which series are "daily" and on keeping the last point exact for end labels, both decided in the spec; averaged values first showed float noise in the tooltip (caught by reviewer) → kit: nothing
- 2026-11-02 Phase 9 export: the spec never said PNG text must wrap, so long captions/subtitles were clipped at phone width (caught by reviewer); the rates panel's y-axis label overlaps its top tick, on screen and in the PNG, left for Phase 10 → kit: validation template should ask for one check at phone width
- 2026-11-02 Phase 10 edge-cases: five of six table rows were already built in earlier phases, so the phase was mostly re-checking; the scale tooltip still reads "rates are always linear" when nothing is selected (harmless, left as is) → kit: roadmap could fold edge-case rows into the phases that build each feature
- 2026-11-02 Phase 11 about-metadata: my own about text overstated two facts ("windows from one year", "as published" for the yoy inflation series), caught by reviewer; Quarto ignored a navbar aria-label and the index page didn't inherit website.description → kit: reviewer prompt should always ask to check prose claims against the code
- 2026-11-02 Tweaks: the owner's first choice for the series picker (a dropdown) was built and then dropped for always-visible checkboxes, and two styling follow-ups came after the spec; the From/To-after-To placeholder became unreachable but stays as a guard → kit: for UI changes, agree on a quick sketch before writing the spec
- 2026-11-02 More series: two requested ids didn't work ("Copper" isn't a FRED id; the OECD Danish CPI stopped in 2025), and twenty series made the colour wrap a real clash → kit: the feature-spec step should check each new symbol's last date before the spec is written
- 2026-11-02 Align specs and brief: roadmap and retro had no entries for the two follow-ups, and BRIEF.md was frozen by a rule while the app moved on, so a second brief (BRIEF-AS-BUILT.md) now tracks the app → kit: a follow-up outside the roadmap still adds a roadmap line and a retro line, and the kit could ship an "as built" brief alongside the original
